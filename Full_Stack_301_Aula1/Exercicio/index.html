Plano de Aprendizado: Desenvolvimento Web

O curso de Desenvolvimento Web é estruturado de forma estratégica para cobrir todas as etapas de criação de aplicações modernas. A primeira metade do curso é totalmente focada no aprendizado de front-end, enquanto a segunda metade é dedicada ao desenvolvimento de back-end. Durante todo o período, o versionamento de código é trabalhado de forma contínua.

Objetivos Principais da Disciplina

  • Ferramentas de Versionamento: Aprendizado prático utilizando Git e GitHub para controle de código.
  • Linguagens de Marcação e Estilo: Estruturação e estilização de documentos através de HTML e CSS.
  • Linguagem de Programação: Desenvolvimento de comportamentos e lógica com JavaScript.
